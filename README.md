# Advent of Code Solutions

Repo for storing my Advent of Code solutions which are written in Python ipynb and sometimes also in Haskell.

### Running the code
- Haskell: load the file for a given day with `ghci <file.hs>` or build/run with `ghc <file.hs> && ./file`.
- Python: using 3.14 or greater, open the notebooks in Jupyter (or VS Code) and run all cells
